So nutzt du die exportierte CSV in Canva

  1. Klick "CSV für Canva exportieren" → Download startet
  2. Canva öffnen, dein SX-Design öffnen
  3. Apps → Bulk Create
  4. CSV hochladen → "Continue"
  5. Pro Variablen-Element (Text/Bild) im Design die passende CSV-Spalte verbinden
  6. "Generate Designs" → Canva produziert ein PDF pro Zeile
  7. Download → PDF Print → ZIP mit allen pixel-perfekten SX

Wichtig: Die Bild-URLs (Sponsor, Signaturen, Logos) zeigen auf deine deployte App. Stelle sicher, dass diese URL öffentlich erreichbar ist (Canva muss die Bilder laden können).
